# Instruções de uso do EF Core

Dentro da pasta **Unievent.Infra**, execute os comandos: 
- `Add-Migration FirstCreate`: Comando para gerar a migração na pasta 'Migrations'
- `Update-Database`: Comando para executar a migração no banco de dados, necessário ter instalado o Sql Server na maquina e não existir antes o mesmo Banco de Dados
